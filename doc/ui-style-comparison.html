What changes — and the new idea:
  • A prominent "What do you want to do with this?" input is the focus; the patterns become suggestion chips below (still one-tap for the common cases).
  • Freeform intent → auto-routed to a pattern via a meta-prompt ("make this shorter" → summarize; "rewrite formally" → rewrite). This is the text sibling of the voice loop (intent → pick a pattern).
  • Keeps the fast path (tap a chip) while adding an open-ended path — the most genuinely "AI-ish" interaction, and unique to the kit.
  • Cost note: auto-routing adds one tiny classifier call before the run; chips skip it. Worth weighing.

🧵 Loom — stays structured

The workbench (Run · Library · Models) is a power/config surface — a big input box doesn't fit a configuration console, and dense native widgets are exactly right. No paradigm change. The only worthwhile move here is a polish pass — more whitespace, clearer section hierarchy, consistent control sizing — so it reads modern rather than form-y, while staying 100% native COSMIC. (Not mocked here; it's refinement, not redesign.)
Recommendation. Keep native COSMIC chrome everywhere (the identity + theming + low maintenance). Apply AI-ish layout only where it fits: session (bubbles + composer) and the quick-action ask box (intent → auto-route). Leave the loom structured (polish only). Net: it feels modern and conversational where it should, and integrated/native everywhere — without becoming a bespoke Electron-style app.
