Fabric on the COSMIC desktop

Feature map & vision — every fabric capability, its desktop usefulness, how we envision it, and what's in place. (Interactive view of fabric-on-the-desktop.md.)

One daemon, one profile, three surfaces.
cosmic-fabricd owns the fabric deployment (the “one channel”); everything else is a thin socket client reading one profile (policy.toml).
🧵 Loom — the Workbench: Run/inspect, Library (curate patterns), Models (instantiations). Configures the rest.
🧰 Kit — quick OS tie-ins: launcher, panel popup, hotkey quick-action. select → inference → review → close.
💬 Session — lightweight multi-turn chat.
+ the socket itself is a 4th, programmatic surface (see the goo appendix in the .md).

Prototyping results & API availability (2026-05-28)

Vision✅ works, locally — llama3.2-vision (7.8 GB, fits the 11 GB GPU; accurate) + via Anthropic claude. Capability rule built & socket-validated (auto-picks a vision model for image runs).
Audio / STT⬜ needs key — fabric transcription is OpenAI-only (whisper / gpt-4o-transcribe); no local option.
Image-gen⬜ needs key — OpenAI or Gemini.
TTS⬜ needs key — Gemini.

Configured: Anthropic + Ollama. Unkeyed in the registry: Gemini, OpenAI (+~26). OpenAI → STT + image-gen; Gemini → TTS + image-gen + Google models. “Antigravity” is not a fabric vendor (it’s Google’s IDE) — use Gemini.
